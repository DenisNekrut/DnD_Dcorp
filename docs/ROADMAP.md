# DnD_Dcorp — актуальная дорожная карта разработки

**Версия плана:** 2.3  
**Обновлено:** 28 ноября 2026  
**Платформа:** веб-приложение (GitHub Pages + NestJS API + PostgreSQL)  
**Игровая система:** D&D 5e  
**Визуальное направление:** тёмная деревянная оболочка портала и песочная игровая поверхность.

## Принципы проекта

- Все игровые механики реализуются по D&D 5e; прежние самодельные механики не используются.
- Сервер — источник истины для авторизации, прав, сохранения и результатов игровых действий.
- Мастер полностью подготавливает комнату; сцены, фигуры и декорации не подставляются автоматически.
- Черновики мастера скрыты от игроков на уровне API, а не только интерфейса.
- Новые функции добавляются небольшими проверяемыми этапами. Готовые ветки вливаются в `main` после успешных проверок; feature-ветки не удаляются.

8. **Следующие игровые функции:** особые свойства оружия, дополнительные атаки, экономика действий и заклинания D&D 5e.

## Критерий готовности игрового стола

Мастер должен иметь возможность с нуля создать комнату, загрузить карту, настроить сетку и слои, расставить персонажей и противников, подготовить скрытые элементы, сохранить черновик и опубликовать сцену. Игроки должны видеть только опубликованные данные и получать изменения без перезагрузки страницы.
