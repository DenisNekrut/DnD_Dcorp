# Хранилище изображений игровых карт

Игровые карты не записываются в JSON состояния комнаты и не помещаются в PostgreSQL. API загружает оригинальный файл в S3-совместимое объектное хранилище, а в состоянии кампании сохраняет только ключ объекта, публичный URL, MIME-тип и размер.

## Поддерживаемые файлы

- PNG, JPEG и WebP.
- Максимальный размер — 15 МБ.
- Тип файла определяется по сигнатуре содержимого, а не только по имени или заголовку браузера.
- SVG и другие активные/неподдерживаемые форматы отклоняются.
- При замене изображения API сначала сохраняет новую ссылку, затем пытается удалить старый объект.

## Переменные окружения API

Добавить в Render → сервис `dnd-dcorp-api` → Environment:

| Переменная | Назначение |
|---|---|
| `S3_ENDPOINT` | S3 API endpoint провайдера |
| `S3_BUCKET` | Название bucket |
| `S3_ACCESS_KEY_ID` | Идентификатор ключа доступа |
| `S3_SECRET_ACCESS_KEY` | Секретный ключ доступа |
| `S3_PUBLIC_BASE_URL` | Публичный домен/URL для чтения объектов |
| `S3_REGION` | Регион; если не задан, используется `auto` |

В `render.yaml` секретные и зависящие от аккаунта значения объявлены через `sync: false`. Реальные ключи хранятся только в настройках окружения Render и не должны попадать в GitHub.

## Настройка провайдера

1. Создать bucket у S3-совместимого провайдера.
2. Создать отдельный API-ключ с правами чтения/записи объектов только в этом bucket.
3. Подключить публичный домен или публичный URL bucket и указать его в `S3_PUBLIC_BASE_URL`.
4. Скопировать endpoint, bucket и ключи в переменные окружения Render.
5. Перезапустить API и проверить загрузку изображения в комнате мастера.

Для Cloudflare R2 endpoint имеет вид `https://<account-id>.r2.cloudflarestorage.com`; регион обычно `auto`. Для `S3_PUBLIC_BASE_URL` используется публичный домен bucket, например отдельный custom domain.

## Доступ и приватность

Загрузка и удаление доступны только владельцу кампании, мастеру или помощнику. Игроки получают ссылку на изображение только вместе с опубликованным состоянием комнаты; неопубликованный черновик по-прежнему скрывается API.

Публичный домен делает объект доступным по его URL. Ключи объектов генерируются случайно и не содержат имён файлов или пользовательского пути. Не включайте публичный просмотр списка объектов bucket. Если проекту потребуется строгая приватность самих файлов даже после публикации, следующий этап — приватный bucket с краткоживущими подписанными URL.

## API

- `POST /api/campaigns/:campaignId/table/map` — загрузка multipart-поля `file`.
- `DELETE /api/campaigns/:campaignId/table/map` — удаление текущей подложки, JSON body: `{"key":"..."}`.

Если S3-переменные не заданы, API продолжает работать, но загрузка карты возвращает `503 Service Unavailable`.
